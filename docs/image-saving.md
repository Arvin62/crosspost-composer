# 导入并保存配图

## 日常使用

- **直接粘贴**：复制排好版的文章或 HTML 源码，粘贴到编辑区。工具保留正文、配图位置、宽度与图注，页面出现“下载并保存配图”提示，点击后开始处理。
- **导入文件**：打开“导入文章”，勾选“同时下载并保存配图”，再选择 HTML / Markdown 文件或粘贴源码并载入。未勾选时先显示占位，稍后也可以点击保存。
- 图片逐张下载，默认采用 **4K 高画质：最大宽度 3840 px、JPEG 质量 95%**，保留原始比例。也可以在设置中选择 1080P（1920 px、92%）、保留原图（不缩放、不重新压缩）或自定义。高画质 PNG 保持 PNG；小图不会被强行放大，当前图片不足长边 1920 / 短边 1080 px 时会提示。选中图片的“替代文字 / 图注”窗口可查看真实像素尺寸。
- 成功图片直接替换原位置的占位，随文章自动保存在当前浏览器，无需重新插图。GIF 保留动画；远程 SVG 暂不自动下载。像素尺寸与原始素材质量决定可保留的细节；4K 预设是宽度上限，不会将不同长宽比的素材裁切成 3840 × 2160。
- 失败图片保留原位置、替代文字和图注。“查看并替换”显示原因，可单张重试或选择本地图片原位替换；图片浮动工具条中的“替换”同样适用。
- 可以停止批量处理，已经完成的图片保留；切换文章、清空或重新导入时，会取消旧任务，避免异步结果覆盖新文章。
- 高清原图需要先完整下载，再在浏览器中按选定画质保存；大图可能需要几分钟。下载过程中显示收到的文件大小，可以随时停止；单张下载最多等待 10 分钟，服务器获取原图最多等待 2 分钟。
- 平台复制会阻止复制尚未保存的占位图。请完成保存、原位换图或删除后再复制。嵌入图片可移除原始外链依赖，公众号、汽车之家是否接受粘贴仍需在平台后台实测。

文章和图片保存于当前浏览器，并不自动同步到另一台设备。迁移时使用完整备份；备份包含待处理图片的位置与来源。成功嵌入的图片不再依赖原始链接。

旧版文章中保留的网络图片，打开或恢复时会保留原位置与来源，转为待保存占位，再由你选择下载。已保存的本地图片继续保留。已有自定义画质设置也会保留，可在设置中切换到 4K 或原图。

## 下载服务

支持跨域读取的公网图源可以由浏览器直接下载。宝马媒体库等不开放跨域读取的图源需要下载服务。服务只接收图片地址，返回图片文件；压缩在浏览器中完成。服务不接收正文，不保存文件，不记录请求 URL，也不转发浏览器的 Cookie、登录信息或来源页。

下载服务使用 Node.js 内置模块，无额外依赖。客户端和服务端单张上限均为 48 MiB；服务端限制超时、最多四次重定向、并发和请求频率，只允许部署者配置的来源站点和图片主机。每次重定向都会重新检查主机与 DNS，拒绝本机、内网、链路本地和特殊地址；连接使用已经验证的 DNS 地址，避免二次解析。

### 本地启动

启动服务：

```bash
IMAGE_ALLOWED_ORIGINS=http://localhost:5173 \
IMAGE_ALLOWED_HOSTS=mediapool.bmwgroup.com,www.audi.cn \
npm run image-service
```

在另一个终端启动页面：

```bash
npm run dev -- --host localhost --port 5173 --strictPort
```

开发页面会通过 `/api/image` 转发给 `127.0.0.1:8787`。本地来源和端口必须与 `IMAGE_ALLOWED_ORIGINS` 相同。使用其他图源时，在 `IMAGE_ALLOWED_HOSTS` 中增加精确主机名；重定向目的主机也需列入。

### 线上部署

GitHub Pages 仅托管页面，不能运行此 Node.js 服务。将 `server/image-service.mjs` 部署到自己的 Node.js 22.12+ 服务器，配置如下：

```bash
IMAGE_ALLOWED_ORIGINS=https://arvin62.github.io \
IMAGE_ALLOWED_HOSTS=mediapool.bmwgroup.com,www.audi.cn \
IMAGE_HOST=127.0.0.1 IMAGE_PORT=8787 \
node server/image-service.mjs
```

通过 HTTPS 反向代理公开 `/api/image`，转发到本机 8787 端口，保留原始 `Origin`，将代理读取超时设置为至少 150 秒。服务仅接受 JSON POST；健康检查为 `/health`。`IMAGE_HOST` 可改为容器需要的监听地址。主机允许列表不能填写 URL、通配符或私有网络主机。

将完整 HTTPS 接口地址填入页面“设置 → 图片下载服务”，例如 `https://images.example.com/api/image`。也可以在构建时配置：

```bash
VITE_IMAGE_SERVICE_URL=https://images.example.com/api/image npm run build
```

此地址是公开服务地址，不应包含密钥或访问凭证。页面的本机设置优先于构建默认值。服务的来源检查不是身份认证，公开部署还应由反向代理限制访问频率和总带宽；不要把服务作为不受限制的通用代理。服务默认不信任转发的客户端 IP，反向代理场景下内置频率限制按代理地址共享。

上线需要分别发布页面和服务，并在真实公众号、汽车之家后台验证粘贴。源码实现和本地测试通过不代表已经发布或目标平台上传成功。
