# 发布记录

### V1.1.1 · 2026-08-13

- 加固导入预清洗：重复移除嵌套构造产生的脚本、嵌入页面和自动加载标签，避免危险标签在单次替换后重新出现。
- 图片地址和样式属性的 HTML 实体改为纯文本白名单解码，不再把未信任文本交给浏览器 DOM 解码后写回资源属性。
- 文档中心的字数统计改为无 DOM 状态机，避免用多字符标签正则处理持久化正文。

### V1.1.0 · 2026-08-13

- 增加格式刷：从光标所在段落吸取段落与光标位置的行内格式，单次应用到目标段落；保留目标文字和链接，可按 Esc 或再次点击按钮取消。
- 单篇 HTML 导出文件名改为“本地日期-文档标题”，并替换常见文件系统保留字符；日期按当前设备的本地时区生成。
- 公共核心改为 Apache License 2.0 开源许可，允许在保留许可证、版权及 NOTICE 声明的前提下使用、修改、分发和商业使用。
- 开放符合 Apache-2.0 inbound=outbound 条款和 DCO 签署要求的外部代码贡献；私有 PRO 产品及其专有代码继续与公共仓库隔离。
- 本次重许可适用于从该日期起发布的公共仓库版本；此前已分发副本继续遵循其获得时的许可证。

### 2026-08-12

- 更新 HTML 清洗依赖，修复其已公开的跨站脚本安全公告；导入文章时仍默认阻止网络图片、远程样式和嵌入资源。
- 增加私下安全报告说明、公开威胁模型和结构化问题模板，避免在公开反馈中泄露未发布稿件、完整备份或凭证。

### V1 · 2026-08-09

图文排版台首个公开版本。

- 支持 HTML / Markdown 导入、富文本编辑和多文档管理。
- 支持图片插入、压缩、裁剪、排序、图注和替代文字。
- 提供多套排版主题、平台发布前检查和多平台复制。
- 支持自动保存、历史版本、查找替换以及完整数据备份与恢复。
- 提供打开即用的在线版本，无需安装、登录或使用终端。
- 导入文章时默认移除网络图片、远程样式和嵌入资源；如需保留网络图片，会明确提示第三方访问风险。
